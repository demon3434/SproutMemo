# SproutMemo 图片附件上传与交互设计规范

本文档详尽记录了 SproutMemo 系统中图片附件上传、即时压缩、原生拖拽排序、自定义命名、原文件名悬停浮显（Tooltip）及大图轮播预览等整套高级 UI 交互与前后端协同设计的实现规范，以供未来项目参考与复用。

## 1. 整体 UI 布局设计

附件上传组件采用响应式网格布局设计（最高支持 9 张图片），每个附件单元呈纵向排布，包含缩略图卡片、右上角醒目删除按钮、次要信息标签（体积大小）和自定义标题输入框四个核心部分。

```
|  题目与解答图片 (最多 9 张)              |
|                                          |
|  [缩略图 1] [缩略图 2] [缩略图 3] [📷+]   |
|   (32.5KB)   (45.1KB)   (28.0KB)         |
|   [标题一]   [标题二]   [标题三]         |
+------------------------------------------+
```

### 3.4 阻止文本框选区触发拖拽操作

当图片卡片容器设置 `draggable="true"` 时，子元素 `<input>` 类型的输入框在点击拖动进行选中文本操作时会由于冒泡触发父容器的 `dragstart` 事件。

为了避免该冲突并保证鼠标选中文本的体验，**必须**在输入框元素上添加以下事件防护：
1. `@mousedown.stop`（阻止 mousedown 事件冒泡，防止浏览器向父容器注册拖动序列）
2. `@dragstart.stop.prevent`（捕获并阻止输入框内部任何拖动行为，确保文本选中逻辑独占鼠标）

示例 HTML 绑定：
```html
<input
  type="text"
  v-model="item.title"
  class="image-title-input"
  placeholder="请给附件命名"
  @click.stop
  @mousedown.stop
  @dragstart.stop.prevent
/>
```

### 4.1 选择与压缩
```javascript
import { compressImage } from '../utils/imageCompressor.js';

const uploadFiles = ref([]);   // 存储实际待上传的 File / Blob 对象
const previewUrls = ref([]);   // 存储本地临时 blob 预览地址
const imageTitles = ref([]);   // 存储每个图片的自定义命名

async function handleFileChange(event) {
  const files = event.target.files;
  if (!files) return;

  for (let i = 0; i < files.length; i++) {
    if (uploadFiles.value.length >= 9) break;
    const file = files[i];
    
    try {
      // 异步 Canvas 压缩 (等比例限制长边 1920，体积 < 1MB)
      const compressedFile = await compressImage(file);
      uploadFiles.value.push(compressedFile);
      previewUrls.value.push(URL.createObjectURL(compressedFile));
      imageTitles.value.push(''); // 上传时命名默认为空，激活 Placeholder
    } catch (err) {
      console.error('Image compression failed, using original:', err);
      // 容错：压缩失败时使用原图
      uploadFiles.value.push(file);
      previewUrls.value.push(URL.createObjectURL(file));
      imageTitles.value.push('');
    }
  }
  event.target.value = ''; // 重置 file 控件
}

function removeImage(index) {
  uploadFiles.value.splice(index, 1);
  previewUrls.value.splice(index, 1);
  imageTitles.value.splice(index, 1);
}
```

### 4.2 拖拽重排算法 (Swapping Handlers)
```javascript
const dragIndex = ref(null);
const dragOverIndex = ref(null);

function handleDragStart(event, idx) {
  event.dataTransfer.effectAllowed = 'move';
  
  // 提取 img 节点作为专属拖动半透明快照层 (去除圆叉和文本输入框干扰)
  const imgEl = event.currentTarget.querySelector('.preview-card img');
  if (imgEl) {
    event.dataTransfer.setDragImage(imgEl, 50, 50);
  }
  
  // 使用 setTimeout 延迟添加 dragging 样式类，防止浏览器截取快照时本身就是透明的
  setTimeout(() => {
    dragIndex.value = idx;
  }, 0);
}

function handleDragOver(event, idx) {
  if (dragOverIndex.value !== idx) {
    dragOverIndex.value = idx;
  }
}

function handleDragEnter(event, idx) {
  dragOverIndex.value = idx;
}

function handleDragLeave(event, idx) {
  if (dragOverIndex.value === idx) {
    dragOverIndex.value = null;
  }
}

function handleDrop(event, targetIdx) {
  dragOverIndex.value = null;
  if (dragIndex.value === null || dragIndex.value === targetIdx) return;
  
  // 同步互换文件、预览链接和自定义标题
  const movedUrl = previewUrls.value[dragIndex.value];
  const movedFile = uploadFiles.value[dragIndex.value];
  const movedTitle = imageTitles.value[dragIndex.value];

  previewUrls.value.splice(dragIndex.value, 1);
  uploadFiles.value.splice(dragIndex.value, 1);
  imageTitles.value.splice(dragIndex.value, 1);

  previewUrls.value.splice(targetIdx, 0, movedUrl);
  uploadFiles.value.splice(targetIdx, 0, movedFile);
  imageTitles.value.splice(targetIdx, 0, movedTitle);
}

function handleDragEnd() {
  dragIndex.value = null;
  dragOverIndex.value = null;
}
```

## 6. 全屏大图预览与物理旋转设计规范

为了提高用户复习和查阅错题的效率，系统提供大图全屏预览功能。支持缩放、轮播以及物理旋转（支持纠正照片拍摄方向错误）。

### 6.1 设计原则与交互规范
1. **屏幕空间最大化利用**：
   - 预览层容器 `.preview-img-wrapper` 的内边距控制在安全间距范围内（推荐 `80px 100px`），使得图片能够尽可能占满屏幕剩余的所有物理空间。
   - 预览大图采用 `object-fit: contain` 自适应缩放，且外层容器不可添加干扰图片完整显示的溢出滚动。
2. **z-index 严格分层分级**：
   - 全屏遮罩层 `.img-preview-overlay` 设置高层级（如 `z-index: 2000`）。
   - 遮罩层内部的控制工具条 `.preview-zoom-controls`、关闭按钮 `.preview-close-btn` 和左右翻页导航按钮 `.nav-btn` **必须** 声明较高层级（如 `z-index: 10`）。
   - 图片容器 `.preview-img-wrapper` 显式声明较低层级（如 `z-index: 1`）。
   - **核心目的**：确保无论图片放大到何种比例，操作工具条与关闭按钮始终保持在图片上方（Z 轴最上），避免被图片遮挡而造成交互卡死。
3. **物理旋转与视觉旋转的结合**：
   - **视觉层旋转**：在全屏预览中，点击“左旋转 90°” (`↺`) / “右旋转 90°” (`↻`) 时，前端仅需通过对 `<img>` 应用 `transform: scale(zoom) rotate(deg)` 进行视觉渲染。
   - **物理层写入**：当用户保存笔记时，如果检测到图片存在旋转偏角（`rotation % 360 !== 0`），前端在触发 Ajax 请求前，**必须** 使用 HTML5 Canvas 载入原始图片并在 Canvas 中执行物理重绘与坐标轴旋转操作，输出为新的物理图片文件并作为上传体发送至后端。此举保证其他终端（如原生 Android app、iPad app）在拉取对应图片附件时已是正确无误的方向，而非依赖前端 css hack 进行适配。

### 6.3 关键的 HTML5 Canvas 物理旋转重绘算法 (`imageCompressor.js`)

在将图片上传/更新至服务端前，检测其 `rotation` 变量。若有偏角，则调用以下物理旋转方法重绘文件：

```javascript
/**
 * 物理旋转图片核心算法
 * @param {File|Blob} file 原始图片文件
 * @param {number} rotation 旋转角度（例如 -90, 90, 180, 270）
 * @returns {Promise<Blob>} 旋转并重绘后的新图片 Blob
 */
export function rotateImageFile(file, rotation) {
  return new Promise((resolve, reject) => {
    let angle = (rotation || 0) % 360;
    if (angle < 0) angle += 360;
    
    if (angle === 0) {
      resolve(file);
      return;
    }

    const img = new Image();
    img.src = URL.createObjectURL(file);
    img.onload = () => {
      URL.revokeObjectURL(img.src);
      const canvas = document.createElement('canvas');
      const ctx = canvas.getContext('2d');

      const is90or270 = angle === 90 || angle === 270;
      const width = is90or270 ? img.height : img.width;
      const height = is90or270 ? img.width : img.height;
      
      canvas.width = width;
      canvas.height = height;

      ctx.translate(width / 2, height / 2);
      ctx.rotate((angle * Math.PI) / 180);
      ctx.drawImage(img, -img.width / 2, -img.height / 2);

      canvas.toBlob((blob) => {
        if (blob) {
          resolve(blob);
        } else {
          reject(new Error('Canvas toBlob 导出失败'));
        }
      }, file.type || 'image/jpeg', 0.95);
    };
    img.onerror = (err) => reject(err);
  });
}
```
